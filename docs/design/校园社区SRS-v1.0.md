## 1 引言

### 1.1 编写目的

本说明书为校园社区网站的设计、开发、测试及课程评审提供需求依据。需求编号用于定位需求及对应的验收记录。

### 1.2 项目背景

学生主要通过群聊等渠道交换校内信息。消息容易被新内容覆盖，不同话题混在一起，已有讨论难以回查。调研同时发现，学生希望能够控制自己帖子的评论，并举报恶意内容。项目围绕结构化浏览、检索、交流与治理建设社区，并提供跑腿任务和虚拟宠物功能。

### 1.3 术语

| 术语         | 说明                                                   |
| ------------ | ------------------------------------------------------ |
| 话题板块     | 按主题组织帖子的栏目，用于浏览、筛选和选择发帖位置。   |
| 可见内容     | 对当前访问者具备查看权限，且仍可公开展示的帖子或评论。 |
| 匿名发帖     | 向普通用户展示匿名标识，同时保留经授权追溯作者的能力。 |
| 私人交接信息 | 跑腿任务中仅参与者及授权管理员可以查看的交接内容。     |

## 2 总体描述

### 2.1 系统目标与范围

提供校内学生交流网站，让学生能从固定板块找到校园信息，也能围绕帖子开展可管理的讨论。项目范围排除二手商品发布与交易。

| 业务类别       | 交付范围                                                       |
| -------------- | -------------------------------------------------------------- |
| 社区基础功能   | 账号与资料、帖子及板块、搜索、点赞与评论、举报及社区管理。     |
| 社区交流功能   | 收藏、匿名发帖、私信联系、站内通知。                           |
| 校园服务与活动 | 有偿跑腿和虚拟宠物。跑腿模块记录约定报酬及进度，款项线下结算。 |

### 2.2 用户角色与场景

| 角色           | 主要场景                                                               |
| -------------- | ---------------------------------------------------------------------- |
| 浏览者         | 按板块浏览、关键词搜索、阅读帖子与规则。                               |
| 学生用户       | 登录后参与讨论，举报违规内容，管理本人的资料与内容。                   |
| 发帖人及评论者 | 学生在具体资源上的身份，用于校验编辑、删除和评论开关权限。             |
| 跑腿任务参与者 | 学生在具体任务中担任发布者或接单人，按该身份推进任务。                 |
| 社区管理员     | 在授权范围内处理举报、维护板块、处置账号、追溯匿名作者和处理跑腿纠纷。 |

### 2.3 运行环境与约束

项目以电脑浏览器为使用和验收环境。浏览者可访问公开内容，受保护操作需要有效会话。管理授权、资源归属与内容可见性由服务端检查。

校内身份校验方式、浏览器版本及服务端部署环境在评审时确认。

## 3 功能需求

### 3.1 功能模块总览

| 模块 | 业务范围           |
| ---- | ------------------ |
| M1   | 访问与账号         |
| M2   | 帖子浏览与发布     |
| M3   | 帖子互动与收藏     |
| M4   | 社区治理与匿名交流 |
| M5   | 私信               |
| M6   | 站内通知           |
| M7   | 跑腿任务           |
| M8   | 虚拟宠物           |

### 3.2 分模块详细需求

#### 3.2.1 M1 访问与账号

##### FR-01 查看社区规则与隐私说明

**参与者与输入**　浏览者打开说明入口，或首次开通学生账号

**处理与规则**　浏览者可查看发布规范、举报方式和个人资料使用范围，首次开通账号时须主动确认。

**输出**　说明页面或规则确认结果

**验收**　进入社区可打开说明。未确认时提交开通，系统阻止开通并提示。

##### FR-02 首次开通社区账号

**参与者与输入**　学生提交校内身份校验信息及规则确认结果

**处理与规则**　学生通过校内身份校验并确认规则后，系统为同一校内身份开通唯一账号。

**输出**　开通结果及失败提示

**验收**　有效身份首次提交可开通。已有账号不重复创建。身份校验失败时提示并保留未开通状态。

##### FR-03 登录并恢复访问

**参与者与输入**　已有账号的学生提交登录信息，或访问需登录的功能

**处理与规则**　已有账号的学生通过登录校验后，可访问自己的数据和授权功能。会话失效时提示重新登录。

**输出**　本人登录会话或验证失败提示

**验收**　验证成功后进入本人账号。验证失败时不建立会话。失效会话访问受保护功能时被拒绝。

##### FR-04 退出登录

**参与者与输入**　已登录学生发出退出请求

**处理与规则**　学生退出后，系统使当前会话失效并清除当前浏览器个人页面的状态。

**输出**　退出结果及退出后的页面状态

**验收**　退出后使用退出前的会话再次访问受保护页面或接口，访问被拒绝。

##### FR-05 维护个人资料

**参与者与输入**　学生提交本人的昵称、头像或个人简介

**处理与规则**　学生可修改自己的昵称、头像和个人简介。系统拒绝无效资料和对他人资料的修改。

**输出**　已保存资料或可修正的校验提示

**验收**　保存有效资料后刷新，显示新资料。提交无效资料或修改他人资料时，原资料保持原值。

#### 3.2.2 M2 帖子浏览与发布

##### FR-06 按板块浏览

**参与者与输入**　浏览者选择一个可用板块

**处理与规则**　浏览者可进入或切换可用板块，查看属于该板块的可见帖子。

**输出**　符合可见规则的板块帖子列表

**验收**　切换板块后只显示该板块的可见帖子。列表为空时显示空状态。

##### FR-07 查看帖子详情

**参与者与输入**　浏览者选择列表中的帖子或打开详情链接

**处理与规则**　浏览者可查看可见帖子的标题、正文和可见评论。访问不可见的帖子时，系统显示不可访问提示。

**输出**　帖子内容、可见评论或不可访问提示

**验收**　打开正常帖子时显示对应内容。使用已删除或下架帖子的旧链接访问时，页面和接口均不返回正文。

##### FR-08 搜索与板块筛选

**参与者与输入**　浏览者输入关键词，可选择需要筛选的板块

**处理与规则**　系统对可见帖子的标题和正文执行关键词搜索，并可同时按所选板块筛选。

**输出**　同时满足查询条件的结果或空状态

**验收**　同时输入关键词和板块后，只返回标题或正文匹配关键词且属于该板块的可见帖子。无匹配时显示空状态。

##### FR-09 发布帖子

**参与者与输入**　有发帖权限的学生提交板块、标题及正文

**处理与规则**　具备权限的学生可选择可用板块并提交非空标题和正文。系统拒绝缺少必填内容或板块已停用的提交。

**输出**　发布结果及可访问的帖子，或提交失败提示

**验收**　有效提交后，帖子显示在对应板块并可打开详情。同一次提交重试只生成一条帖子。

##### FR-10 查看我的帖子

**参与者与输入**　已登录学生打开我的帖子

**处理与规则**　学生可查看本人发布的帖子及其状态，列表按发布时间倒序排列。

**输出**　本人发帖记录、发表时间和状态

**验收**　多个帖子按发布时间倒序显示。尝试读取其他学生的管理列表时，系统拒绝访问。

##### FR-11 编辑自己的帖子

**参与者与输入**　发帖人提交本人帖子的标题、正文或板块变更

**处理与规则**　发帖人可对本人处于可编辑状态的帖子更新标题、正文或板块，原有点赞和评论保留。

**输出**　更新后的帖子或禁止编辑提示

**验收**　保存后列表、详情和搜索显示更新内容。他人不可编辑，编辑操作不得使已下架的帖子重新公开。

##### FR-12 删除自己的帖子

**参与者与输入**　发帖人确认删除本人的帖子

**处理与规则**　发帖人确认后可删除自己的帖子。删除后该帖停止公开与互动。

**输出**　删除结果及公开入口更新

**验收**　列表和搜索不再返回该帖，旧链接不显示正文，新增点赞与评论被拒绝。他人发起删除时被拒绝。

#### 3.2.3 M3 帖子互动与收藏

##### FR-13 点赞与取消点赞

**参与者与输入**　已登录学生对可见帖子提交点赞或取消请求

**处理与规则**　已登录学生可对可见帖子点赞或取消点赞，同一账号对同一帖子至多计一次。

**输出**　本人的点赞状态及更新后的数量

**验收**　两种操作均同步更新状态与数量，刷新后保持一致。重复请求不会重复计数。

##### FR-14 发表评论

**参与者与输入**　有评论权限的学生对可见帖子提交评论正文

**处理与规则**　有评论权限的学生可对开放评论的可见帖子提交非空评论。

**输出**　显示新评论，或提示内容无效、评论关闭等原因

**验收**　有效提交后评论在对应详情页可见，刷新后仍可查看。空白评论、评论关闭后的直接提交均被拒绝。

##### FR-15 开启或关闭帖子评论

**参与者与输入**　发帖人对本人帖子提交开启或关闭评论的请求

**处理与规则**　发帖人可以为本人帖子开启或关闭评论。关闭期间已有评论仍按可见规则展示。

**输出**　更新后的评论开关状态

**验收**　关闭后页面与接口拒绝新增评论。重新开启后可继续评论。他人无法修改开关。

##### FR-16 删除自己的评论

**参与者与输入**　评论者确认删除自己的评论

**处理与规则**　评论作者可确认删除本人评论。帖子关闭评论时仍可执行删除。

**输出**　删除结果及更新后的评论数

**验收**　确认后评论正文不再公开，评论数同步更新。其他普通用户不能代删。

##### FR-23 收藏与取消收藏

**参与者与输入**　已登录学生收藏可见帖子、取消收藏或打开收藏页

**处理与规则**　已登录学生可收藏可见帖子，并从本人的收藏列表查看或取消收藏。

**输出**　更新后的本人收藏列表

**验收**　收藏变更刷新后保留。帖子失效后，收藏页面和接口不展示其正文。

#### 3.2.4 M4 社区治理与匿名交流

##### FR-17 举报违规帖子或评论

**参与者与输入**　已登录学生选择违规帖子或评论并填写举报原因

**处理与规则**　学生可选择原因并提交举报。同一举报人对同一内容已有待处理举报时，系统沿用已有记录。

**输出**　新的待处理举报或已有举报状态

**验收**　有效举报生成待处理记录，重复提交不新增待处理记录。其他普通用户无法查看举报人身份。

##### FR-18 查看举报处理结果

**参与者与输入**　举报人打开本人的举报记录

**处理与规则**　举报人可查看本人举报的处理状态及结论。

**输出**　待处理状态或处理结论

**验收**　处理前显示待处理状态，结案后显示结论。尝试读取他人举报记录时被拒绝。

##### FR-19 处理举报与违规内容

**参与者与输入**　授权管理员选择举报记录，提交结论、理由及内容处置决定

**处理与规则**　有处置权限的管理员核查待处理举报并保存结论，可下架违规帖子或隐藏违规评论，同时记录处置理由。

**输出**　处理结论、内容可见状态和处置记录

**验收**　举报人可看到处理结论。下架或隐藏内容无法通过列表、搜索、详情或旧链接向普通用户公开。

##### FR-20 限制与恢复账号权限

**参与者与输入**　授权管理员选择账号及要设置或解除的限制范围，设置时说明理由

**处理与规则**　有账号处置权限的管理员可设置或解除发帖、评论限制。系统向受限用户说明理由，限制到期自动恢复。

**输出**　更新后的发帖或评论权限及处置记录

**验收**　限制、解除或到期后，对应操作的权限随即更新并可查处置记录。

##### FR-21 维护话题板块

**参与者与输入**　授权管理员提交板块新增、修改或停用操作

**处理与规则**　有权限的管理员可新增、修改或停用板块。停用后禁止新发帖并保留已有帖子记录。

**输出**　更新后的板块入口及发帖选项

**验收**　板块入口和发帖选项随变更更新。向停用板块直接提交新帖时被拒绝。

##### FR-22 使用授权管理功能

**参与者与输入**　访问者请求管理页面或执行具体管理操作

**处理与规则**　只有具备相应权限的管理员可使用对应管理功能。系统在管理页面、接口及实际操作时校验权限。

**输出**　授权范围内的管理结果或拒绝提示

**验收**　无权限用户及权限已撤销的管理员无法读取对应管理数据或完成操作。

##### FR-24 可选择匿名发帖

**参与者与输入**　具备发帖权限的学生提交帖子并选择匿名

**处理与规则**　学生可在发帖时选择匿名。该帖向普通用户仅展示匿名标识，授权管理员可按规定追溯。

**输出**　公开侧显示匿名标识，授权侧保留可追溯记录

**验收**　普通用户查看列表、搜索、详情或相应接口时无法识别匿名作者账号。

##### FR-25 按权限追溯匿名作者

**参与者与输入**　有追溯权限的管理员选择匿名帖并填写核查理由

**处理与规则**　有追溯权限的管理员填写理由后可查询核查所需的账号信息。系统记录查询人、时间和理由。

**输出**　核查所需的账号信息及查询记录

**验收**　授权且理由有效时可得到必要信息，未授权查询被拒绝。查询后匿名帖公开展示仍为匿名。

#### 3.2.5 M5 私信

##### FR-26 管理私信联系申请

**参与者与输入**　学生发起联系申请，接收方提交确认决定

**处理与规则**　未建立联系时，一方可发起联系申请，接收方可同意或拒绝。同一双方的待处理申请不重复生成。

**输出**　待处理、同意或拒绝结果

**验收**　同意后双方可互发私信。拒绝后仍不可发送。非接收方无法处理申请。

##### FR-27 发送和查看私信

**参与者与输入**　学生选择会话并提交消息，或请求查看本人会话

**处理与规则**　已建立联系的学生可相互发送私信，消息仅会话双方可查看。

**输出**　对会话双方可见的消息或拒绝提示

**验收**　双方确认联系后可发送且刷新后保留。未建立联系时发送被拒绝，第三方无法读取会话。

##### FR-28 终止私信联系

**参与者与输入**　已建立联系的学生提交终止请求

**处理与规则**　已建立联系的任一方可以终止联系。历史消息仍对会话双方可见。

**输出**　联系状态更新及对参与双方可见的历史消息

**验收**　终止后双方发新消息均被拒绝。重新申请并获得同意后，可恢复发送。

#### 3.2.6 M6 站内通知

##### FR-29 查看站内通知

**参与者与输入**　学生打开本人的通知列表或阅读一条通知

**处理与规则**　系统向相关学生提供评论、联系申请及跑腿任务的进度通知。学生阅读后可查看已读状态。

**输出**　对应通知、已读状态和受权限约束的跳转结果

**验收**　本人可看到对应事件并标记已读。通知跳转遵守目标内容权限。验收覆盖评论、联系申请和跑腿进度三类通知。

#### 3.2.7 M7 跑腿任务

##### FR-30 浏览与筛选跑腿任务

**参与者与输入**　已登录学生打开任务列表，可选择筛选条件

**处理与规则**　已登录学生可按条件查看任务概要、报酬和状态，默认显示未过期的待接单任务。

**输出**　任务概要、报酬和状态

**验收**　筛选结果符合所选条件。过期任务不能接取。

##### FR-31 发布跑腿任务并确认完成

**参与者与输入**　发布者提交内容、报酬和截止时间，或确认接单人提交的完成结果

**处理与规则**　有权限的学生提交任务内容、有效报酬和截止时间后发布。接单人提交完成后，发布者可确认结案。

**输出**　待接单或已完成状态

**验收**　有效发布后为待接单，接单人提交完成后为待确认，发布者确认后为已完成。流程仅记录报酬信息。

##### FR-32 接取并提交完成

**参与者与输入**　非发布者选择待接单任务，接单成功者随后可提交完成

**处理与规则**　非发布者可接取未过期的待接单任务。接单成功后可为该任务提交完成。

**输出**　接单结果，或更新为待确认

**验收**　多人同时接取时仅一人成功。只有该接单人可提交完成，提交后状态为待确认。

##### FR-33 查看我参与的任务

**参与者与输入**　学生打开本人参与的跑腿任务

**处理与规则**　学生可分别查看本人发布和接取的任务及进度。私人交接信息仅任务参与者和授权管理员可见。

**输出**　分类展示本人发布和接取的任务及进度

**验收**　两类任务列表归属正确。非参与者和未授权管理员无法读取私人交接信息。

##### FR-34 取消跑腿任务

**参与者与输入**　参与者申请取消，或处理对方发起的取消申请

**处理与规则**　待接单任务由发布者直接取消。已接单或待确认任务由一方申请、另一方同意后取消。

**输出**　取消处理结果及相应任务状态

**验收**　单方请求不会取消需要双方同意的任务。取消后不得再接单、提交完成或确认完成。

##### FR-35 反馈与处理跑腿纠纷

**参与者与输入**　参与者提交纠纷，授权管理员填写处理意见和必要的调整理由

**处理与规则**　任务参与者可提交纠纷并查看处理意见。授权管理员可处理，状态调整须记录理由。

**输出**　可供参与者查看的意见及处置记录

**验收**　参与者可看到处理意见，处置可追溯。流程保留处理记录，款项仍由参与者线下处理。

#### 3.2.8 M8 虚拟宠物

##### FR-36 查看虚拟宠物成长

**参与者与输入**　已登录学生打开宠物页面

**处理与规则**　学生首次进入宠物页面时创建初始宠物，后续显示已保存的成长值、阶段和成长规则。

**输出**　本人的宠物阶段、成长值及成长规则

**验收**　首次进入后再次访问不重复初始化，展示的成长数据与已保存状态一致。

##### FR-37 签到增加成长值

**参与者与输入**　已有宠物的学生提交签到

**处理与规则**　有宠物的学生可每日签到。按北京时间自然日，同一账号只在首次签到时增加成长值。

**输出**　本次签到结果及当前成长值

**验收**　同日重复或并发签到只增加一次。刷新后成长值仍一致。

## 4 非功能需求

### 4.1 性能与浏览器可用性

#### NFR-07 电脑浏览器可用性

**要求**　通过约定的电脑浏览器完成全部模块的核心操作，核心页面应避免内容遮挡和页面级横向滚动。

**验证**　在约定的浏览器及窗口大小下逐一执行各模块的核心流程，页面可阅读且关键控件可操作。

**来源**　调研报告

#### NFR-08 首屏加载时间 暂定

**要求**　电脑浏览器清空缓存，在下行 1.6 Mbps、上行 750 kbps、往返延迟 150 ms 的条件下，首页首屏加载暂定为 3 秒内。

**验证**　从发起首页导航计时，到首屏帖子标题可见且列表可滚动时停止。测试数据量与取值方法在评审时确认。

**来源**　调研报告

### 4.2 可靠性与一致性

#### NFR-03 数据一致性

**要求**　同一任务只允许一人成功接单，同一账号在同一天只获得一次签到成长值。随跑腿与宠物模块验收。

**验证**　分别并发提交接单和签到请求，检查结果、刷新后界面状态与业务记录一致。

#### NFR-04 提交可靠性

**要求**　帖子和跑腿任务提交失败或结果未确认时保留填写内容，提示结果并允许重试。同一次提交最多生成一条记录。

**验证**　分别模拟请求未送达与操作已保存但响应中断，网络恢复后重试，最终只生成一条记录。

#### NFR-05 数据可恢复性

**要求**　系统支持从成功备份恢复账号、帖子、评论及其他模块的相关数据。

**验证**　在隔离环境恢复备份，核对数据清单及关联关系。测试账号可登录并查看对应内容。核对范围包含收藏、匿名关联、私信、站内通知、跑腿任务及宠物成长记录。

### 4.3 隐私、访问安全与可追溯性

#### NFR-01 隐私保护

**要求**　公开页面及对应接口不返回作者学号、手机号和真实姓名等非公开资料。系统按角色限制匿名作者信息与会话访问。

**验证**　分别使用浏览者、普通学生和无关第三方账号检查列表、搜索、详情及接口响应，无非公开字段或越权内容。

#### NFR-02 访问安全性

**要求**　系统在服务端校验受保护操作所需的登录状态、角色授权和资源归属。

**验证**　退出后、权限撤销后或以非资源所有者身份直接访问对应接口，均被拒绝，不返回受保护数据，也不改变业务状态。

#### NFR-06 管理操作可追溯性

**要求**　系统记录关键管理操作的操作者、时间、目标、动作和理由。审计记录仅向授权人员开放，操作执行者不能修改或删除既有记录。

**验证**　分别执行内容下架、账号限制与匿名追溯，检查记录字段完整，并验证未授权读取及执行者修改均被拒绝。

## 5 外部接口需求

### 5.1 用户接口

| 入口           | 主要交互                                                                   | 权限边界                                     |
| -------------- | -------------------------------------------------------------------------- | -------------------------------------------- |
| 浏览入口       | 板块列表、搜索、帖子详情、规则与隐私说明。                                 | 只返回当前访问者可见内容。                   |
| 账号及个人中心 | 开通、登录、退出、资料、本人帖子、举报、收藏、私信、通知、跑腿任务和宠物。 | 本人数据及个人操作需要相应会话与权限。       |
| 管理入口       | 举报处置、账号限制、板块维护、匿名追溯及跑腿纠纷处理。                     | 每项管理操作分别授权，页面及接口均进行检查。 |

### 5.2 外部软件接口

校内身份校验需要提供校验结果和用于判定账号唯一性的身份依据。接入方式、字段范围、错误返回和联调环境待确认。

## 6 数据需求

### 6.1 业务数据与可见范围

| 数据对象         | 关键业务数据                                         | 可见性与一致性规则                                                       |
| ---------------- | ---------------------------------------------------- | ------------------------------------------------------------------------ |
| 账号及资料       | 校内身份依据、账号、昵称、头像、简介及权限状态。     | 同一校内身份仅开通一个账号，公开接口不返回非公开身份字段。               |
| 板块、帖子及评论 | 板块归属、作者、标题、正文、评论开关和可见状态。     | 删除或下架的帖子停止公开访问和互动。评论关闭时，已有可见评论保留。       |
| 互动与举报       | 点赞关系、收藏关系、举报对象、处理状态及结论。       | 单账号对同一帖子只计一次点赞。同一举报人对同一内容只保留一条待处理举报。 |
| 匿名、私信与通知 | 匿名标识、联系申请、会话、消息和通知读取状态。       | 匿名作者信息按授权追溯。会话仅双方可查看，通知仅接收方可读。             |
| 跑腿任务及纠纷   | 发布者、接单人、任务内容、报酬、截止时间、处理意见。 | 一项任务至多有一名接单人，私人交接信息遵守 FR-33。                       |
| 虚拟宠物及签到   | 宠物、阶段、成长值和签到日期。                       | 每个账号只初始化一次。北京时间同日签到只增加一次成长值。                 |
| 管理操作记录     | 操作者、操作时间、目标、动作和理由。                 | 记录只向授权人员开放，执行者不能修改或删除既有记录。                     |

### 6.2 数据备份与恢复

备份及恢复验收参照 NFR-05。备份核对范围覆盖各交付模块的业务数据，并检查关联关系。备份频率、保留期限和恢复目标待评审。

## 7 隐私与社区治理要求

首次开通账号前提供可阅读的社区规则及个人资料使用说明，并由学生主动确认。说明应覆盖发布规范、举报方式及个人资料使用范围（FR-01）。

普通用户所见页面及接口应遵守非公开身份字段的披露限制（NFR-01）。匿名追溯限授权人员使用，填写核查理由并记录查询过程（FR-25、NFR-06）。

举报结论可由举报人查看，已下架的内容停止公开访问。处理结果、账号限制及相关管理操作应依权限规则保存和查询（FR-18 至 FR-22、NFR-06）。

## 8 验收标准

### 8.1 账号与社区核心功能验收

| 验收场景         | 预期结果                                                                                 | 关联需求       |
| ---------------- | ---------------------------------------------------------------------------------------- | -------------- |
| 公开浏览与检索   | 按板块浏览并搜索。打开可见帖详情，结果符合板块及可见性约束。                             | FR-06 至 FR-08 |
| 学生账号全流程   | 校验通过后开通唯一账号，登录后维护本人资料，退出后旧会话无法继续使用。                   | FR-01 至 FR-05 |

### 8.2 质量与安全验收

使用浏览者、学生、管理员与权限已撤销的管理员交叉检查页面和接口权限。模拟提交响应中断后重试，核对内容只创建一次。使用备份演练恢复并核对数据及关联。首屏性能按 NFR-08 的暂定口径记录，具体测量方案待确认。
